# 快速启动指南

## 第一步：安装 MySQL

确保已安装 MySQL 8.0 或更高版本，并启动 MySQL 服务。

## 第二步：创建数据库

打开命令行，执行：

```bash
mysql -u root -p
```

输入密码后，执行：

```sql
source database/schema.sql
```

或者使用 MySQL Workbench 等工具导入 `database/schema.sql` 文件。

## 第三步：配置数据库连接

编辑 `src/main/resources/application.properties` 文件：

```properties
spring.datasource.username=root
spring.datasource.password=你的MySQL密码
```

## 第四步：启动项目

### 方式一：使用启动脚本（推荐）

双击运行 `start.bat` 文件

### 方式二：使用命令行

```bash
# Windows
mvnw.cmd spring-boot:run

# Linux/Mac
./mvnw spring-boot:run
```

### 方式三：使用 IDE

在 IntelliJ IDEA 或 Eclipse 中：
1. 导入项目（Maven 项目）
2. 找到 `StudentScoreSystemApplication.java`
3. 右键运行 main 方法

## 第五步：访问系统

打开浏览器访问：http://localhost:8080

## 常见问题

### 1. 端口被占用

修改 `application.properties` 中的端口：
```properties
server.port=8081
```

### 2. 数据库连接失败

检查：
- MySQL 服务是否启动
- 用户名密码是否正确
- 数据库名称是否为 `student_score_system`

### 3. Maven 依赖下载慢

配置 Maven 镜像，编辑 `~/.m2/settings.xml`：

```xml
<mirrors>
    <mirror>
        <id>aliyun</id>
        <mirrorOf>central</mirrorOf>
        <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
</mirrors>
```
