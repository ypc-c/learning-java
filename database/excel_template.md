# Excel 成绩导入模板说明

## 文件格式
- 文件类型：.xlsx 或 .xls
- 第一行为表头（会被跳过）
- 从第二行开始为数据

## 列格式（按顺序）

| 列号 | 列名 | 说明 | 示例 |
|------|------|------|------|
| A | 学号 | 学生学号（必须存在于系统中） | 2024001 |
| B | 平时成绩 | 0-100的数字 | 85 |
| C | 期中成绩 | 0-100的数字 | 90 |
| D | 期末成绩 | 0-100的数字 | 88 |

## 示例数据

```
学号      平时成绩  期中成绩  期末成绩
2024001   85       90       88
2024002   78       82       85
2024003   92       95       93
```

## 注意事项
1. 学号必须是系统中已存在的学生
2. 成绩必须是0-100之间的数字
3. 系统会自动计算总成绩、等级和绩点
4. 如果学生已有成绩，会自动更新
