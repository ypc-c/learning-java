# 校园图书管理微服务系统 - 项目运行说明

## 一、环境要求

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | 已安装（注意：Java 9+ 需额外 JAXB 依赖，项目已包含） |
| Maven | 3.9+ | 已安装 |
| Node.js | 18+ | 已安装（v24.14.0） |
| MySQL | 8.0 | 需要运行中，root 密码为 `123456` |
| Nacos Server | 3.2.0 | 项目目录自带 |
| RabbitMQ | 4.3.0 | 项目目录自带，需 Erlang OTP |
| Sentinel Dashboard | 1.8.9 | 项目目录自带 |
| Zipkin Server | 2.24 | 可选，用于链路追踪 |

## 二、启动步骤

### 第一步：初始化数据库

1. 启动 MySQL 服务，确保 root 密码为 `123456`（可在各服务 `application.yml` 中修改）
2. 执行 SQL 初始化脚本：
   - 打开 MySQL 客户端，执行 `sql/init.sql`
   - 脚本自动创建 4 个数据库（library_user / library_book / library_borrow / library_notice）
   - 预置种子数据：3 个用户、5 本图书、3 条公告

### 第二步：启动基础设施

1. **启动 Nacos Server**（服务注册与配置中心）
```bash
cd nacos-server-3.2.0/nacos/bin
startup.cmd -m standalone
```
访问: http://127.0.0.1:8848/nacos （用户名/密码：nacos/nacos）

> ⚠️ **注意**：Nacos 3.x 会占用 8080 端口作为辅助 HTTP 端口，因此 Gateway 改用 **8086** 端口。

2. **启动 RabbitMQ**（消息中间件）
   先安装 Erlang OTP（`rabbitmq/rabbitmq/otp_win64_28.5.exe`），再安装 RabbitMQ（`rabbitmq/rabbitmq/rabbitmq-server-4.3.0.exe`）
```bash
rabbitmq-plugins enable rabbitmq_management
```
访问: http://127.0.0.1:15672 （用户名/密码：guest/guest）

3. **启动 Sentinel Dashboard**（服务容错监控）
```bash
java -jar sentinel/sentinel/sentinel-dashboard-1.8.9.jar --server.port=8090
```
访问: http://127.0.0.1:8090 （用户名/密码：sentinel/sentinel）

4. **启动 Zipkin Server**（分布式链路追踪，可选）
```bash
java -jar zipkin-server-2.24.0-exec.jar
```
访问: http://127.0.0.1:9411

### 第三步：编译并启动微服务

在 `library-parent` 目录下一次性编译全部模块：
```bash
cd library-parent
mvn clean install -DskipTests
```

**推荐：一键启动（方式一）**
使用项目自带的启动脚本：
```bash
start-all.bat
```

**手动逐个启动（方式二）：**
```bash
# 终端1 - user-service (端口 8081)
cd user-service && mvn spring-boot:run

# 终端2 - book-service 实例1 (端口 8082)
cd book-service && mvn spring-boot:run

# 终端3 - book-service 实例2 (端口 8083) —— 演示负载均衡
cd book-service && mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8083"

# 终端4 - borrow-service (端口 8084)
cd borrow-service && mvn spring-boot:run

# 终端5 - notice-service (端口 8085)
cd notice-service && mvn spring-boot:run

# 终端6 - gateway-service (端口 8086)
cd gateway-service && mvn spring-boot:run
```

### 第四步：启动前端

```bash
cd library-frontend
npm install
npm run dev
```
访问: http://localhost:5173

前端 Vite 代理已配置，自动将 `/user`、`/book`、`/borrow`、`/notice` 前缀请求转发至 Gateway (8086)。

## 三、核心功能演示步骤

### 1. 用户注册与登录
- 打开 http://localhost:5173 ，点击"立即注册"
- 注册时默认角色为**学生**（管理员账号由系统预置，不支持自主注册管理员）
- 使用注册的账号或预置测试账号登录
- 登录后系统自动存储 token + userId + role，可直接使用全部功能

### 2. 浏览与借阅图书
- 登录后进入图书列表页，可搜索图书（按书名关键词）
- 点击图书进入详情页，查看库存信息
- 点击"立即借阅"发起借阅（需先登录）
- 借阅成功后库存自动扣减

### 3. 借阅管理
- 进入"我的借阅"查看当前借阅记录
- 点击"归还"完成还书操作，库存自动恢复
- 逾期未归还的记录会被定时任务检测并通过 RabbitMQ 发送提醒

### 4. 通知公告
- 进入"通知公告"查看公共公告和个人逾期提醒
- 逾期提醒由 borrow-service 定时任务自动检测 → RabbitMQ → notice-service 自动生成

### 5. 管理后台（ADMIN 角色）
- **用户管理**：查看全部注册用户列表（角色标签、状态、注册时间）
- **图书管理**：添加、编辑、删除图书
- **借阅管理**：查看所有用户借阅记录
- **公告管理**：发布、删除公告

## 四、七大核心技术验证

### 1. Nacos（服务注册 + 配置管理）
- 访问 http://127.0.0.1:8848/nacos → 服务管理 → 服务列表
- 应看到 5 个服务：user-service、book-service（2 实例）、borrow-service、notice-service、gateway-service
- 每个微服务通过 `spring.application.name` 注册，Gateway 通过 `lb://服务名` 动态路由
- 本地配置 `application.yml` 已禁用 Nacos Config 强校验（`spring.cloud.nacos.config.import-check.enabled=false`）

### 2. Spring Cloud LoadBalancer（负载均衡）
- book-service 部署 2 个实例（8082 和 8083），Nacos 中实例数 = 2
- 通过网关多次访问 `/book/list`，两个实例控制台日志交替输出，验证轮询策略生效

### 3. OpenFeign（声明式服务调用）
- borrow-service 通过 `@FeignClient` 调用 user-service（`GET /user/{id}` 验证用户存在）和 book-service（库存扣减/恢复）
- 查看 borrow-service 启动日志可看到 Feign 接口代理初始化

### 4. Sentinel（流量控制 + 熔断降级）
- 访问 Sentinel Dashboard: http://127.0.0.1:8090
- user-service 的 `/login` 和 `/register` 接口配置了 `@SentinelResource` 限流
- 快速连续点击登录按钮触发限流 → 返回 429 "Too many login attempts"
- Gateway 层也配置了 SCG 全局流控

### 5. Spring Cloud Gateway（API 网关）
- 所有请求通过 http://localhost:8086 统一入口
- `AuthGlobalFilter` 全局过滤器：白名单（`/user/login`、`/user/register`）放行，其余路径校验 JWT
- 管理员路径（`/book/add`、`/user/list` 等）额外校验 ADMIN 角色
- 未登录访问受保护接口 → 401 "Missing or invalid Authorization header"
- 学生访问管理员接口 → 403 "Admin access required"

### 6. Spring Cloud Stream + RabbitMQ（消息驱动）
- borrow-service 的 `@Scheduled` 定时任务检测逾期记录 → 通过 StreamBridge 发送到 RabbitMQ
- notice-service 监听 `overdue-exchange` 交换机 → 消费消息 → 自动创建逾期提醒通知
- 验证：手动触发 `POST /borrow/overdue-check`，查看 RabbitMQ 管理界面

### 7. Sleuth + Zipkin（分布式链路追踪）
- 访问 Zipkin UI: http://127.0.0.1:9411
- 进行一次完整借阅操作（Gateway → borrow-service → [Feign] user-service / book-service）
- Zipkin 中可看到完整 Trace，含每个 Span 的耗时

## 七、常见问题排查

### 1. Gateway 启动报端口占用
- **原因**：Nacos 3.x 默认占用 8080 端口
- **解决**：Gateway 已改为 8086，确保 Nacos 比 Gateway 先启动

### 2. 服务启动报 `No spring.config.import set`
- **原因**：Spring Cloud 2021.x 要求显式配置 `spring.config.import`
- **解决**：已在各服务 `application.yml` 中配置 `spring.cloud.nacos.config.import-check.enabled=false`

### 3. 登录返回 500 / `NoClassDefFoundError: DatatypeConverter`
- **原因**：Java 17 移除了 JAXB 模块，JJWT 0.9.1 依赖它
- **解决**：已在 `library-common/pom.xml` 中添加 `javax.xml.bind:jaxb-api` 依赖

### 4. 注册用户报 `Column 'create_time' cannot be null`
- **原因**：MyBatis-Plus 未配置自动填充处理器
- **解决**：已在 `MyBatisPlusConfig.java` 中添加 `MetaObjectHandler` Bean

### 5. 借书提示"请先登录"
- **原因**：登录后未存储 userId
- **解决**：登录/注册接口现在返回 `{token, userId, username, role}`，前端完整存储

### 6. JDBC 连接报 `Unsupported character encoding 'utf8mb4'`
- **原因**：Java 不识别 `utf8mb4` 编码名
- **解决**：所有 JDBC URL 中 `characterEncoding` 改为 `UTF-8`
